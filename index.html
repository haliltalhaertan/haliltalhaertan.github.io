01 / About

I am interested in memory: how it can arise on its own in simple dynamical systems, and how it can be stored and searched cheaply in practical ones. One line of work studies network automata whose connections are shaped by the dynamics: particles form and break bonds, a Boolean rule runs on the resulting graph, and the question is what such systems can store. Another line measures compact memory retrieval for conversational agents against standard baselines such as BM25. I prefer exact or exhaustively checked results, negative results reported as such, and fully reproducible code.

Interests: cellular automata, adaptive networks, complex systems, artificial life, information retrieval.

02 / Papers & research

Memory without mechanics: exact analysis of a particle-network automaton with rule-driven bonds

H. T. Ertan · Autogenesis U0 · Preprint, 2026

Code & reproduction Claims ledger

Autogenesis U0 couples damped particles in 3D, distance-based bonds with hysteresis, and a Boolean rule on the bond graph. On rest scaffolds, the particle positions stay fixed while the bonds and node states can continue to change. The reported exhaustive search covers 491 connected graph classes: all graphs with three to six nodes, and seven-node graphs with at most ten candidate edges. Exactly one class supports the specified clocked two-bit register, with seven nodes and ten candidate bonds.

The register has an explicit physical realization, but remains fragile under single-node and bond flips. The tested matched-null comparisons do not establish an advantage beyond the graph properties controlled for. These results concern the specified model settings and search family; they do not establish robust memory or spontaneous self-assembly of the register.

The public repository includes the reference engine, equivalence and invariance checks, reproduction scripts, and a claim-by-claim ledger. See the README for pinned versions and reproducibility caveats.

Twelve Bytes Against an Inverted Index: What a Compact-Code Memory Retrieval Programme Found, and Which Configuration Choices Decided It

H. T. Ertan · Manuscript, 2026

Paper, data ledger & code

Can a 12-byte code per document replace or complement a BM25 index when an agent searches its conversational memory? In the reported four-benchmark exploratory programme, it did not beat BM25 on any measured axis. Five configuration choices (document unit, query cohort, projection family, benchmark and metric) each reversed a verdict with everything else fixed. Two lossless compactions leave every output bit unchanged while cutting the encoder vocabulary by about 63% and the BM25 index by about 76%.

Local exploratory pilot; not preregistered or for citation. The programme's code has not been independently audited.

03 / Research updates

LLMZIP Public Research Brief

16 October 2026 · Documentation-only exploratory research snapshot

A context-selection research brief with aggregate findings, methodological limitations, and a proposed independent evaluation. Independent validation has not yet been carried out.

The published pilot reports 419 correct answers with full retrieved sessions and 417 with an older anchored selector, across 487 previously seen questions. Successful final reader calls used 23.2% fewer input tokens with the selector. These figures do not establish equivalent accuracy, generalization or end-to-end cost savings: there was no clean holdout, the questions form one session-connected component, and failed calls, output tokens and evaluation costs are excluded.

This is the 16 October public snapshot, not a new experiment. It does not validate the newer full-exchange packer or untested router variants. Proposed independent evaluation.
